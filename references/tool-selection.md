# 按画面需求选择工具

用户允许采用效果更适合的插件，工具选择不被锁死在 Remotion / HyperFrames。但更换须以当前实际可用能力和样片效果为依据，不能仅凭产品描述声称更好。

**用户已明确决定不使用 Runway。** 此 skill 不调用 Runway 的账号检查、上传、生成、套餐查询或其他工具；环境中存在此插件也不自动启用。默认采用内置 ImageGen＋本地 Remotion。未来用户明确指定其他插件时再检查对应能力与条件。

| 画面需要 | 优先路径 | 选择理由与边界 |
| --- | --- | --- |
| 本参考的纸质插画、档案、拼贴底图 | 内置 ImageGen＋Remotion | ImageGen 做材质与主体，Remotion 做精确中文、图解、运动和总帧数；当前默认路线 |
| 检索流程、关系树、年代与准确字幕 | Remotion SVG 或 HyperFrames HTML/GSAP | 确定性细线动画与精确时长；优先复用既有工程 |
| 洞窟／书房／机械等主体镜头 | ImageGen 插画＋本地分层／SVG 动画 | 推镜、视差、物件与路径运动；复杂主体动作超出当前能力时明确说明，不冒充已生成的动作 |
| 数字人／讲解主持人 | 已连接 HeyGen | 仅用户明确要人物讲解时；默认静音参考不需要数字人 |
| 高精度三维机械运动 | 现有 Blender 工程及可用执行工具 | 仅有具体三维需求且环境可用时；不默认安装大型新技术栈 |

其他插件的目录说明不代表生成效果实测。用户指定其他插件时，以当前连接状态、实际接口和样片为准，不把旧快照作为永久可用或不可用结论。不要自动搜集凭据或承诺已安装；插件镜头仍需统一字幕、画幅、fps 和完整视频时长。

HyperFrames 以 HTML 合成为源，可控制媒体、字幕和可寻址 timeline；本地渲染与可选托管服务是不同路径，参见 [官方 Quickstart](https://hyperframes.heygen.com/quickstart)。本次没有把云渲染、账户或 credits 纳入默认流程。

插件生成镜头须与 storyboard 的目标时长协调；在用户授权与工具实际约束内裁剪、保持或延展镜头，最后以整片 ffprobe 检查。保持图像主体与风格一致，不自动复制参考片原始镜头、字幕、水印或音轨。
