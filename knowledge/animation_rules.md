# 动画与叙事

画面先确定主体与主视觉最完整的构图，再加运动。每场只选择支持该内容的运动：档案物件入画、剪纸拼贴层次、细线绘制、检索路径、关系树生长、年份跳转或轻推镜。粒子用于“离散信息汇聚”等明确隐喻，避免长时间无意义背景。

通常先给观众看到问题或物件，接着显现机制与关系，最后停留阅读。进入约 0.4–0.8 秒；退场约 0.3–0.6 秒；其余时间由字幕阅读与解释复杂度分配。非常短的场景应按比例缩短动画。所有进入、停留和转场属于该场景的时间预算。

Remotion 的视觉只依赖 frame / fps 与确定性数据，不用 CSS animation、setTimeout、Date.now 或未设种子的随机数推进动画。要随机分布纹理／粒子时固定 seed；要加载图像字体时等待真实加载。HyperFrames 用暂停的 GSAP timeline 交给渲染器 seek，不独立 autoplay。

避免全片同构。概念片可混合纸上插画、实例物件与流程图；历史片可混合档案、地图、年代与关系树。非常短片至少保持一个清晰视觉变化，长片围绕新信息扩展场景而非重复卡片。
